# Milestone 5A — guided scanning

Implemented: explicit browser capability/permission inspection; user-initiated video-only getUserMedia; camera stop, unmount/late-grant cleanup, disconnection and hidden-page handling. Localhost or HTTPS is required; permission prompts and camera availability are browser/OS dependent. No automatic camera activation. Chrome-family, Firefox and Safari expose differing Permissions API support; an unavailable permission query falls back to getUserMedia on explicit start.

The unmirrored preview is a square center crop. Align each face to the 72% guide. OpenCV samples small 3×3 sticker-interior patches using median scaled 8-bit Lab values; dispersion and clipped/dark pixel fractions reduce quality. All six face centers calibrate six color identities under the same local light. Reject poor/overlapping center samples. Classify by nearest Lab center and return every sticker's residual, quality, margin and heuristic confidence. The confidence is not a measured probability or recognition accuracy.

Orientation instructions come from the backend convention table, looking directly at each face: U top B/right R; R top U/right B; F top U/right R; D top F/right R; L top U/right F; B top U/right L. Rotate the whole cube without changing pieces between captures. This version requires the standard six-color scheme; the fixed grip/face alignment is user supplied. No automated cube pose, face localization, unseen-face inference or continuous move tracking is claimed here.

Review all 54 labels; correct dropdown classifications without increasing their measured confidence. Centers are calibration anchors and require recapture if wrong. An explicit review acknowledgement gates canonical validation. Reachability checks enforce color counts, piece uniqueness, corner/edge orientations and permutation parity; errors suggest reviewing colors and face orientation. Legal reachability does not certify that the photograph was interpreted correctly. A successful state transfers to Explorer and is revalidated through the same canonical engine before adoption.

API: GET `/api/vision/guide`; POST `/sample` with bounded JPEG/PNG; POST `/assemble` with exactly six nine-sample observations; POST `/validate` with reviewed 54-letter URFDLB facelets. Header dimensions are checked before OpenCV decode (96–1280px, <=1.5MB), finite numeric channels validated. OpenCV is headless, so no desktop GUI dependency. Photos stay transient in the scan page and local API request. Only reviewed state, Lab calibration, confidence and correction indices enter the session-local transfer; no photos are persisted or transmitted to external services.

Acceptance tests: real OpenCV operations on deterministic controlled JPEG grids, four exact engine states at three noise levels; six-center ambiguity/quality rejection; low confidence at a color midpoint; bad data/formats/dimensions; impossible flip/color counts and rotated-center rejection; complete API sampling/classification/validation path. Frontend checks secure context, unsupported capture, permission errors, no automatic camera opening, late-grant cleanup, six captures, explicit review, corrections preserving uncertainty, and validated handoff. These synthetic images are not physical webcam accuracy evidence. The user has been asked to perform a real six-face scan; any observed result must be recorded separately from automated checks.

Known limits: fixed frontal face alignment, diffuse stable light, no arbitrary palettes, no in-plane rotation auto-correction, no continuous tracking. Reflective/glossy stickers, similar red/orange hues, shadows, occlusion and misorientation can require recapture or manual correction.

Technical references (data only): [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia), [OpenCV color conversions](https://docs.opencv.org/4.x/d8/d01/group__imgproc__color__conversions.html). The local app follows explicit user permission and secure-context requirements; scaled Lab calibration is a project heuristic, not a library-provided cube detector.
